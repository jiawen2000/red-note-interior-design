```
└──────────────────────┬───────────────────────────────┘
                       ↓ 觸發 report:ready 事件
┌──────────────────────────────────────────────────────┐
│  #cover　封面（第一個版面）                            │
│  主標 + 副標（「小紅書」紅字）+ 記者 / 日期             │

│  .section × 10    每一節 = 一個小標 + 段落 + 多媒體模組 │
│                   小標一路標下去，沒有章節大標          │
│                                                       │
│  內文中的名詞（卷、限高、私人集運、包郵、文公尺、        │
│  封號、起號、網感）點擊後才跳出解釋框                   │
└──────────────────────┬───────────────────────────────┘
                       ↓
│  #footer　頁尾（論文資訊；不放章節連結）                │

固定元件：
  #progress-bar　頂部 3px 閱讀進度條（桌機 / 手機皆同）
  .to-top　　　　右下角回到頂端（捲過一屏後出現）
```

**版面原則**（依 `version2.docx`）
- 照片與圖說一律置中，多張照片的組合也整組置中
- 照片不做滿版排版，全部保留左右留白
- 第一段與後續內文的字級、顏色完全相同，不做首字放大
- 受訪者引言以一般內文呈現，不另外做引言區塊
- 頁面寬度永遠等於瀏覽器寬度，不會出現左右捲動

## 五、多媒體模組速查表

**這一節是你自由編排版面的工具箱。** 每個模組都是獨立的一段 HTML，
在 `index.html` 裡複製、貼上、上下調換順序，就能改變版面，不需要動 CSS。
所有模組都會自動置中。

### 1. 單張照片

```html
<figure class="m-single wrap-media reveal">
  <img src="assets/img/檔名.jpg" alt="照片描述">
  <figcaption class="caption">△ 圖說文字。</figcaption>
</figure>
```

### 2. 兩張並排

```html
<figure class="m-pair wrap-media reveal">
  <div class="m-pair__grid">
    <img src="assets/img/A.jpg" alt="">
    <img src="assets/img/B.jpg" alt="">
  </div>
  <figcaption class="caption">△ 圖說文字。</figcaption>
</figure>
```

### 3. 三張組合（左大右二）

```html
<figure class="m-trio wrap-media reveal">
  <div class="m-trio__grid">
    <img src="assets/img/大圖.jpg" alt="">
    <img src="assets/img/小圖1.jpg" alt="">
    <img src="assets/img/小圖2.jpg" alt="">
  </div>
  <figcaption class="caption">△ 圖說文字。</figcaption>
</figure>
```

### 4. 多張照片網格（四張以上）

```html
<figure class="m-grid wrap-media reveal">
  <div class="m-grid__items">
    <img src="assets/img/1.jpg" alt="">
    <img src="assets/img/2.jpg" alt="">
    <!-- 要幾張就放幾張 -->
  </div>
  <figcaption class="caption">△ 圖說文字。</figcaption>
</figure>
```
預設兩欄。照片總數為奇數時，最後一張會自動橫跨整列，維持整體置中。
想改成三欄：把 `m-grid` 改成 `m-grid m-grid--3`

### 5. 影片

```html
<figure class="m-video wrap-media reveal"
        data-video-type="file"
        data-video-src="assets/video/檔名.mp4">
  <div class="m-video__frame">
    <img src="assets/img/劇照.jpg" alt="">
    <button class="m-video__play" type="button" aria-label="播放影片"></button>
  </div>
  <figcaption class="caption">△ 圖說文字。（影片）</figcaption>
</figure>
```

| 類型 | data-video-type | data-video-src 填什麼 |
|---|---|---|
| 本地 mp4 | `file` | `assets/video/xxx.mp4` |
| YouTube | `youtube` | 影片 ID（網址 `watch?v=` 後面那串） |
| Vimeo | `vimeo` | 影片 ID（純數字） |

> `data-video-src` **留空**時，會自動只顯示劇照並標示「影片待補」，版面不會壞。
> 目前「呂映昇的家」那則就是這個狀態，等影片檔備好再把路徑填進去即可。
>
> ⚠︎ GitHub Pages 單一檔案上限 100MB。影片若超過 50MB，建議放 YouTube
> （設為「不公開」也能嵌入）而不是直接放進倉庫。

### 6. 互動圖表

HTML：
```html
<figure class="m-chart wrap-media reveal">
  <div class="m-chart__box">
    <h4 class="m-chart__title">圖表標題</h4>
    <p class="m-chart__sub">副標說明</p>
    <div class="m-chart__canvas" data-src="data/chart-新檔名.json"></div>
    <p class="m-chart__source">資料來源：⋯⋯</p>
  </div>
</figure>
```

對應的 `data/chart-新檔名.json`：
```json
{
  "type": "bar",
  "unit": " 家",
  "items": [
    { "label": "X軸標籤", "sublabel": "第二行（選填）",
      "value": 3000, "display": "長條上顯示的字（選填）", "highlight": false }
  ]
}
```

改數字只要動 JSON，不用碰 HTML。
目前 `charts.js` 支援 `"type": "bar"`（長條圖）；要加折線圖、圓餅圖，
在 `assets/js/charts.js` 的 `RENDERERS` 物件裡新增一個函式即可，其他程式碼都不用改。

### 7. 名詞解釋（點擊才跳出）★新增

**兩個步驟：**

① 在 `data/glossary.json` 的 `terms` 裡加一組：
```json
"名詞": "解釋文字。"
```

② 在 `index.html` 內文中，把那個名詞包起來：
```html
<button class="term" type="button" data-term="名詞">名詞</button>
```

就完成了，不需要寫任何程式碼。

- 名詞在內文中維持原本字級與顏色，只加**紅色虛線底線**提示可以點
- 讀者按下去，解釋框才會跳出來，出現在名詞下方（下方空間不夠會自動翻到上方）
- 關閉方式：再按一次名詞、按框外任一處、按 Esc、或按框右上角的 ✕
- 解釋框寬度會自動夾在瀏覽器範圍內，不會造成左右捲動

目前已建立 8 個名詞：卷、限高、私人集運、包郵、文公尺、封號、起號、網感。

## 六、常見修改

### 改配色 / 字級

只要改 `assets/css/00-base.css` 最上面的 `:root` 變數，全站會一起變：

| 變數 | 目前值 | 用途 |
|---|---|---|
| `--c-bg` | `#f0f0f0` | 正文底色 |
| `--c-text` | `#000000` | 文字主色 |
| `--c-sub` | `#454545` | 圖說、日期等輔助資訊 |
| `--c-accent` | `#ac231a` | 小標底線、名詞標記 |
| `--c-dark` | `#1B1A20` | 封面 / 載入畫面底色 |
| `--c-brand-red` | `#FE231D` | 「小紅書」商標紅、進度條 |

字級用 `clamp()` 寫成自動縮放，改 `--fs-body` 等變數即可，不需要另外寫 RWD。

### 改載入畫面行為

`assets/js/preloader.js` 最上方的 `CONFIG`：

| 設定 | 目前值 | 說明 |
|---|---|---|
| `AUTO_ENTER` | `true` | 載完自動進入。改成 `false` 會顯示「進入報導」按鈕，由讀者點擊才進入 |
| `MIN_DURATION` | `1200` | 最短停留毫秒數，避免快網速時載入畫面一閃而過 |
| `MAX_DURATION` | `30000` | 保險閥：超過就強制放行，避免某張照片壞掉害讀者卡住 |

## 九、瀏覽器與無障礙

- 支援：Chrome / Safari / Edge / Firefox 近三年版本，含 iOS Safari、Android Chrome
- 斷點：`700px`（照片組改單欄堆疊）
- 頁面寬度永遠等於瀏覽器寬度，`html` 與 `body` 皆設 `overflow-x: hidden`
- 已處理：`prefers-reduced-motion`、所有照片有 `alt`、名詞按鈕有 `aria-expanded`、可用鍵盤操作（Tab 選取、Enter 展開、Esc 關閉）
- 不支援 IE

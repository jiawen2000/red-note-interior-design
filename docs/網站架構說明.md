**版面原則**（依 `version2`～`version6`）
- 照片與圖說一律置中，多張照片的組合也整組置中
- 照片不做滿版排版，全部保留左右留白
- 第一段與後續內文的字級、顏色完全相同，不做首字放大
- 內文（含第一段）的「小紅書」不轉紅字，只有標題類才用商標紅
- 受訪者引言以一般內文呈現，不另外做引言區塊
- 名詞只加紅色虛線底線，不加圓點
- 載入百分比兩位數以上不補 0（顯示 `85%`、`100%`）
- 頁面寬度永遠等於瀏覽器寬度，不會出現左右捲動
- 「狼性」的名詞標記直接做在小標上，不重複標在內文
- 封面遮罩調亮，讓背景影片看得更清楚
- 照片不做滿版；**影片可以滿版**（沉浸式與 scrub 區塊）
- 報導開場前兩段用 `#8E8E8E`、字級 75%，與後續正文之間以 Favicon 圖形分隔
- 照片圖說一律**靠左**（影片上的浮動圖說仍置中）
- 三張組圖改為「上方一張大圖、下方兩張並排」，三張都維持原始比例不裁切
- 署名統一用「製作：林佳玟」
- 封面右上角有聲音開關，**預設開啟**（瀏覽器擋下時先靜音，讀者點一下就開）
- ⚠ `html` / `body` 必須維持 `overflow-x: clip`，**不能改回 `hidden`**，
  否則三個 sticky 影片區塊會全部失效

## 五、多媒體模組速查表

**這一節是你自由編排版面的工具箱。** 每個模組都是獨立的一段 HTML，
在 `index.html` 裡複製、貼上、上下調換順序，就能改變版面，不需要動 CSS。
所有模組都會自動置中。

### 1. 單張照片

```html
<figure class="m-single wrap-media reveal">
  <img src="assets/img/檔名.jpg" alt="照片描述">
  <figcaption class="caption">△ 圖說文字。</figcaption>
</figure>
```

### 2. 兩張並排

```html
<figure class="m-pair wrap-media reveal">
  <div class="m-pair__grid">
    <img src="assets/img/A.jpg" alt="">
    <img src="assets/img/B.jpg" alt="">
  </div>
  <figcaption class="caption">△ 圖說文字。</figcaption>
</figure>
```

### 3. 三張組合（上大下二）

```html
<figure class="m-trio wrap-media reveal">
  <div class="m-trio__grid">
    <img src="assets/img/大圖.jpg" alt="">
    <img src="assets/img/小圖1.jpg" alt="">
    <img src="assets/img/小圖2.jpg" alt="">
  </div>
  <figcaption class="caption">△ 圖說文字。</figcaption>
</figure>
```
第一張橫跨整列當大圖，第二、三張並排在下方。三張都維持原始比例，**不會被裁切**。
（舊版是「左大右二」，左邊那張為了對齊右側總高度必須裁切，version7 已改掉。）

### 4. 多張照片網格（四張以上）

```html
<figure class="m-grid wrap-media reveal">
  <div class="m-grid__items">
    <img src="assets/img/1.jpg" alt="">
    <!-- 要幾張就放幾張 -->
  </div>
  <figcaption class="caption">△ 圖說文字。</figcaption>
</figure>
```
預設兩欄。照片總數為奇數時，最後一張會自動橫跨整列。
想改成三欄：把 `m-grid` 改成 `m-grid m-grid--3`

### 5. 影片

```html
<figure class="m-video wrap-media reveal"
        data-video-type="file"
        data-video-src="assets/video/檔名.mp4">
  <div class="m-video__frame">
    <img src="assets/img/劇照.jpg" alt="">
    <button class="m-video__play" type="button" aria-label="播放影片"></button>
  </div>
  <figcaption class="caption">△ 圖說文字。（影片）</figcaption>
</figure>
```

| 類型 | data-video-type | data-video-src 填什麼 |
|---|---|---|
| 本地 mp4 | `file` | `assets/video/xxx.mp4` |
| YouTube | `youtube` | 影片 ID |
| Vimeo | `vimeo` | 影片 ID（純數字） |

> 留空時會自動只顯示劇照並標示「影片待補」，版面不會壞。

### 6. 沉浸式滿版影片（小紅書精華剪輯）

sticky 釘在畫面上 → 淡入並放大到滿版 → 循環播放（**有聲**）→ 停止播放 → 淡出 → 解除 sticky。

```html
<section class="m-immersive" aria-label="影片說明">
  <div class="stage">
    <video class="stage__video"
           src="assets/video/檔名.mp4" poster="assets/img/底圖.jpg"
           loop playsinline preload="metadata"></video>
    <div class="m-immersive__scrim" aria-hidden="true"></div>
    <p class="m-immersive__caption">△ 圖說文字。</p>
  </div>
</section>
```

- **不要**加 `wrap-media`，也**不要**加 `muted` —— 靜音與否由 `scroll-fx.js` 依聲音開關決定
- 停留時間：改 `07-video-scroll.css` 裡 `.m-immersive` 的 `--immersive-scroll`
  （桌機 260vh、手機 220vh）
- 各階段的進度區間集中在 `scroll-fx.js` 最上方的 `CONF.immersive`

### 7. Scroll scrub 影片（捲動位置 = 播放進度）★version6 新增

不是自動播放，而是把捲動位置直接對應到 `video.currentTime`：
往下滑影片前進、往上滑影片倒退、停止捲動就停在當前影格。

```html
<section class="m-scrub" aria-label="影片說明">
  <div class="stage">
    <video class="stage__video"
           src="assets/video/檔名.mp4" poster="assets/img/底圖.jpg"
           muted playsinline preload="auto"></video>
    <div class="m-scrub__scrim" aria-hidden="true"></div>
    <p class="m-scrub__loading">LOADING</p>
    <p class="m-scrub__caption">△ 圖說文字。</p>
    <div class="m-scrub__progress" aria-hidden="true"><i></i></div>
  </div>
</section>
```

- 播完一遍需要的捲動距離：`.m-scrub` 的 `--scrub-scroll`（桌機 400vh、手機 300vh）。
  **影片越長就給越多距離**，否則滑一下就播完
- 一定要 `muted` `playsinline` `preload="auto"`，且**不要**加 `controls`
- 程式不呼叫 `video.play()`，只設定 `currentTime`；`loadedmetadata` 之前不會計算，
  metadata 一到位就立刻同步到目前的捲動位置
- Safari 對頻繁 seek 較敏感，因此差距小於 `SEEK_THRESHOLD`（0.02 秒）就不重新 seek

### 7. 互動圖表

HTML 一律長這樣，換 `data-src` 就換一張圖：

```html
<figure class="m-chart wrap-media reveal">
  <div class="m-chart__box">
    <h4 class="m-chart__title">圖表標題</h4>
    <p class="m-chart__sub">副標說明</p>
    <div class="m-chart__canvas" data-src="data/chart-檔名.json"></div>
    <p class="m-chart__source">資料來源：⋯⋯</p>
  </div>
</figure>
```

`charts.js` 依 JSON 裡的 `type` 決定畫哪一種：

| type | 用途 | 互動方式 |
|---|---|---|
| `bar` | 少數幾個數值的比較 | 滑過長條顯示數值 |
| `line` | 時間趨勢（含統計趨勢線與自動偵測高點） | 滑過折線顯示每月數值；**滑到或點擊紅點**看該次高點的事件 |
| `stackedBar` | 多類別隨時間的組成變化 | 滑過區塊顯示各類金額；**點擊圖例**單獨檢視某一類 |

**折線圖 JSON**（`chart-google-trends.json`）：
```json
{
  "type": "line",
  "yLabel": "相對熱度",
  "series": [ { "t": "2010-01-01", "v": 0 } ],
  "trend":  { "slope": 0.4275, "perYear": 5.13, "intercept": -8.9, "r2": 0.816 },
  "annotationsSrc": "data/chart-google-trends-annotations.json",
  "hints":  [ "滑鼠移到折線上可看每月的搜尋熱度" ],
  "explain": "以報導口吻解釋統計結果，用 \n 分段。",
  "source":  "資料來源：⋯⋯"
}
```

- `trend` 會在圖上畫一條虛線的線性趨勢線，並在圖例顯示「每年 +N，R² = X」
- **`annotationsSrc`** 指向獨立的關鍵事件檔。繪圖資料與事件判讀分開存放，
  改事件不用動繪圖資料，反之亦然
- 事件檔的 `anomalies` 陣列每一筆會變成圖上的一個紅點，欄位包括
  `t`（年-月）、`v`（實際值）、`expected`（模型預期）、`deviation`、`direction`（▲▼）、
  `shortLabel`（紅點提示的標題）、`tooltip`（說明）、`confidence`（可信度）、`note`（延伸判讀）
- 事件檔另外還有 `method`（分析方法）、`background`（季節係數）、`levelShifts`（基準線跳升）、
  `notLabeled`（刻意不標註的月份）與 `sources`（新聞出處）。目前網頁只畫 `anomalies`，
  其餘欄位供論文引用

**堆疊長條圖 JSON**（`chart-customs-furniture.json`）：
```json
{
  "type": "stackedBar",
  "unit": "億元",
  "categories": [ { "key": "9401", "name": "座具（沙發、椅子）", "color": "#ac231a" } ],
  "items": [
    { "label": "2024", "values": { "9401": 78.8, "9403": 119.7 } },
    { "label": "2026", "sublabel": "1–7月", "partial": true, "values": { } }
  ]
}
```
`partial: true` 的長條會用半透明呈現，代表資料不完整（例如只統計到 7 月）。

**兩張圖共用的底部區塊**（`hints` / `note` / `source`）會自動整理成 bullet，
靠左對齊，左緣對齊圖表的 Y 軸位置：

| 欄位 | 用途 |
|---|---|
| `hints` | 字串陣列，操作說明（例如「滑鼠移到折線上可看每月的搜尋熱度」） |
| `note` | 資料解讀提醒，會用深色加粗呈現 |
| `source` | 資料來源，字級最小；太長會自然換行 |

`tooltipMode: "valueOnly"` 讓滑鼠提示只顯示金額，不重複年份與類別。

**圖表配色**（沿用主視覺，色彩節制）：

| 用途 | 色碼 |
|---|---|
| 主要類別（座具／沙發） | `#ac231a` 強調紅 |
| 次要類別（其他家具） | `#1B1A20` 墨黑 |
| 第三類（寢具） | `#6d6b75` 中灰 |
| 第四類（燈具） | `#b3b1b8` 淺灰 |
| 折線、事件標註 | `#ac231a` / `#FE231D` |

要新增圖表類型（圓餅圖、散布圖⋯⋯），在 `assets/js/charts.js` 的 `RENDERERS`

### 調整捲動節奏

三個區塊的捲動距離都寫成 CSS 變數，集中在 `07-video-scroll.css`：

| 變數 | 桌機 | 手機 | 意義 |
|---|---|---|---|
| `--hero-scroll`（`#cover-scroll`） | 220vh | 200vh | 封面停留多久才離場 |
| `--immersive-scroll`（`.m-immersive`） | 260vh | 220vh | 精華剪輯停留多久 |
| `--scrub-scroll`（`.m-scrub`） | 400vh | 300vh | 影片播完一遍要捲多遠 |

各階段（淡入、放大、播放、淡出）落在進度的哪一段，集中在 `scroll-fx.js`
最上方的 `CONF`：

```js
const CONF = {
  cover:     { textOut: [0.00, 0.30], videoOut: [0.55, 0.92] },
  immersive: { fadeIn: [0, 0.12], fadeOut: [0.86, 1], scaleIn: [0, 0.20], play: [0.05, 0.90] },
  scrub:     { fadeIn: [0, 0.06], fadeOut: [0.94, 1], scaleIn: [0, 0.10] }
};
```

數字是「該區塊捲動進度的 0～1」。例如封面的 `textOut: [0, 0.30]` 代表
標題在前 30% 的捲動距離內淡完，`videoOut: [0.55, 0.92]` 代表影片要等到
55% 之後才開始淡出 —— 這就是「第一次滾動只淡標題、第二次才淡影片」。

### Google Trends 的統計處理

**繪圖資料**（`chart-google-trends.json`）
- 起點裁切為 **2010 年 1 月**，保留 200 個月，數值未做任何加工
- 趨勢線：對 200 個月做最小平方線性迴歸，**每年 +5.13 點**，R² = **0.816**

**關鍵事件標註**（`chart-google-trends-annotations.json`，你自己做的分析）
- 分析區間 2016-10～2026-08 共 119 個月（更早的月份多為 0，是 Google Trends
  低於門檻的截斷值，不適合做季節分解）
- 分解方式：實際值 ÷（12 個月中心移動平均 × 該月季節係數）＝ 殘差
- 異常判準：殘差偏離 1 超過 1.5 個標準差（殘差標準差 0.140，約 ±21%）
- **結論一**：11 月的季節係數 1.204，九年中有八年成立；12 月 1.082、九年中七年成立。
  歷年 11 月的高點是**結構性雙 11**，模型不需要任何事件就能預測，因此**不標成事件高峰**
- **結論二**：基準線出現三次跳升——2018 +31%（成因不明）、2021 +38%（三級警戒）、
  2024 +49%（小紅書在台爆發）
- **結論三**：2024 年的跳升在 1～9 月就已完成，早於 10 月 15 日宣布的 20 億運費補貼。
  **補貼是追認，不是成因**，論文請勿寫成因果
- 圖上的 7 個紅點是去除趨勢與季節後仍然偏離的月份，成因判讀與可信度都寫在標註檔裡

**海關資料的解讀提醒**：這是台灣自中國大陸進口 HS 9401/9403/9404/9405
